# Benford-s-Law-Capstone
I was trying to see whether or not a large data set would follow the principle of Benford's Law, or if Benford's Law was only applicable in specific situations.
I used the Population data from all towns and cities in the United States which was obtained through the US Census.
I utilized Excel to analyze the large data set and compare it to the expected proportions given by Benford's Law.
I found that the population data followed the expected values of Benford's Law.
